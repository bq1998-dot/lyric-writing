# Suno V6 字段与滑块

> 交付 V6 任务时读。字段上限、负向词字段、商业录音室修正行为、
> Style Influence / Variety 的调法，以及交付时顺手一起给的五项固定动作。

---

## Suno V6 字段与滑块（2026-09-18 核实）

2026-09-09 Suno 发布 V6 家族（v6 / v6-wild / v6-mini），**同时下线全部旧模型**——
V5、V4.5、V4 已从模型选择器里消失。网上绝大多数提示词指南描述的是**用户已经选不到的模型**。
实测字段上限（与 V5.5 相同，V6 未收紧）：

| 字段 | 上限 | 说明 |
|---|---|---|
| Lyrics | 5000 字符 | 约 3000 字符之后后端开始赶拍 |
| Styles | 1000 字符 | |
| **Exclude Styles** | 1000 字符 | **V6 独立的负向词字段** |
| Title | 100 字符 | **会被当上下文用**，不要空着 |
| Duration | 10–360 秒 | 仅自定义模式生效；不填按 20 秒处理 |

### 四条必须在交付时提醒用户的 V6 行为

**① 负向词绝不能内联写进 Style 框 —— 必须放 Exclude Styles 字段。**
写进 Style 框的 `no autotune` 等于"给我加 autotune"，V6 会把它当正向指令读。
（生成后 Styles 面板会把负向词**带减号回显**在 style 后面，看着像模型改了你的提示词——
不是，那是 Exclude 字段被渲染回来了，你的原文一字未动。）

**② V6 内置「商业录音室修正」，会抹平毛刺 —— 这是它与老版本最大的行为差异。**
V6 与华纳 / BMG / Believe 联合开发，模型会自动圆滑高频尖峰、用中频胶水填满乐器之间的
空隙。**症状：提示词越精确，越容易被吃掉棱角**，出来"干净但边缘是软的"。
凡靠质感取胜的风格（cranked tube amp 的毛边、gritty 人声的颗粒、lo-fi 的脏、失真类）
都要在 Exclude 里把这层修正排掉，典型串：
`polished production, glossy mix, pitch-corrected vocals, autotune, synthetic drums, quantized grid, clean modern sheen`

**③ Style Influence 默认 50%，Variety 控制两次 take 的离散度。**
Style Influence 默认 50% ＝ 一份写得再细的提示词，**一半的权威在出声前就被丢掉了**——
这是"提示词明明很具体、成品却还是大白话"的第一嫌疑点，建议上调（70–80% 是合理起点），
**但官方未公布最优值，只能建议用户自己 A/B，不要当定论交付**。
Variety 决定两次 take 的差异——**V6 的 take-to-take 方差可以大于一次有意的提示词改动**，
所以"改一个字再生成"这种验证方式在 V6 上会失真：要验改动是否有效，先把 Variety 调低。

**④ V6 读段落 cues，不只是 Style 框。**
段落标签与器乐标签的作用比旧版更明确——「交付格式六条」第 1、4 条因此更要守。

### 交付 V6 任务时的固定动作

写词之外的这五项**顺手一起给**（都属于"歌词能不能落地"的范畴，不算曲风/混音/发行建议，
不违反硬性禁令）：① Exclude 串（照抄或按风格改写）② Style Influence / Variety 的调法
③ Duration 建议值 + 依据（按小节数估算，见下）④ 3 个 Title 候选（含字数核验）
⑤ Style 框字符数核验。

**时长估算要跑脚本**：`总小节数 × (60/BPM × 4)`，并把各段落小节数明细列出来供用户复核。
V6 实测普遍比旧版**多出 20–30 秒**，估算值要留这个余量。
