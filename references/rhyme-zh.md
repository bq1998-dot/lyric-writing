# 中文十三辙韵脚速查

> 按通行「十三辙」分类。数字为该字的声调：**1 阴平 · 2 阳平 · 3 上声 · 4 去声**
> 上声（3 声）字在长音落点难唱——副歌核心句的韵脚优先选 1、2、4 声。

---

## 1. 发花辙 · a / ia / ua

- **1声** 家 花 沙 他 她 加 拉 搭 抓 刷 瓜 夸 挖 掐 妈 疤
- **2声** 茶 查 麻 爬 拿 华 划 牙 芽 娃 侠 峡 杂 砸 闸
- **3声** 把 打 傻 哑 卡 甲 假 耍 瓦 垮 马 洒 塔
- **4声** 话 下 怕 大 那 骂 挂 化 画 价 架 嫁 辣 蜡 纳 踏

**气质**：直白、明亮、口语感强。适合明快小调、口语说唱。

---

## 2. 梭波辙 · o / e / uo

- **1声** 多 波 说 哥 歌 锅 桌 捉 摸 坡 拖 脱 喝 遮 车 科 棵
- **2声** 何 河 合 得 佛 国 活 罗 锣 磨 魔 挪 婆 蛇 舌 折 泽
- **3声** 我 火 伙 果 裹 可 渴 舍 者 扯 躲 朵 锁 索 所 妥
- **4声** 过 错 落 做 坐 座 破 迫 热 色 社 射 设 特 各 个 课 刻 客 这 握

**气质**：顿挫感强、口语。适合民谣、说唱、叙事。

## 3. 乜斜辙 · ie / üe

- **1声** 些 街 结 缺 靴 爹 跌 憋 撇
- **2声** 别 学 决 绝 节 洁 协 邪 斜 爷 鞋 携 觉 叠
- **3声** 写 雪 血 姐 解 铁 撇 也 野 且 瘪
- **4声** 夜 谢 界 借 切 却 确 月 越 悦 灭 列 烈 裂 业 叶 卸 泄

**气质**：轻巧、俏皮、略带疏离。适合轻快小曲、戏谑表达。

## 4. 一七辙 · i / ü / er

- **1声** 知 之 枝 诗 西 希 低 机 基 衣 一 依 居 虚 需 区 趋 鱼
- **2声** 时 十 实 食 齐 其 奇 离 梨 皮 疲 迷 题 提 余 于 如 儿
- **3声** 里 理 起 己 几 你 比 笔 米 底 抵 雨 与 语 举 曲 取 许 耳 尔
- **4声** 字 事 是 志 记 气 意 义 地 第 力 立 利 密 必 去 句 具 遇 律 绿 二

**气质**：细密、私语、有锋利感。适合内心独白、说唱、体量小的抒情。

## 5. 姑苏辙 · u

- **1声** 书 输 出 呼 忽 姑 孤 哭 夫 租 粗 初 铺 苏
- **2声** 无 图 途 徒 如 儒 湖 壶 糊 胡 独 读 毒 服 竹 逐 熟 俗
- **3声** 古 苦 虎 舞 五 武 补 谱 普 土 吐 组 阻 主 煮 鼠 数 属
- **4声** 路 露 度 渡 树 数 处 住 助 附 负 复 富 父 妇 不 步 部 布 木 目 幕 入

**气质**：压抑、封闭、沉闷。适合苦情、沉重叙事。注意这个辙可选字偏少，
长篇容易翻来覆去，慎用于长歌。

## 6. 怀来辙 · ai / uai

## 7. 灰堆辙 · ei / ui

- **1声** 飞 非 灰 归 龟 追 推 吹 催 亏 黑 杯 悲 堆 威 微 徽
- **2声** 回 谁 垂 随 肥 梅 眉 煤 雷 累 围 为 违 唯 陪 赔
- **3声** 水 美 悔 毁 鬼 轨 嘴 腿 北 给 每 尾 伟 委
- **4声** 泪 累 碎 醉 对 队 贵 脆 会 汇 惠 慧 味 位 未 卫 费 废 肺 背 倍 被 配 佩 睡 税 退 岁 兑

**气质**：哀婉、下坠、有余韵。**失恋与遗憾题材的经典辙口**——注意「泪 / 累 / 碎 / 醉」
这四个字极易被用滥，整首歌最多用其中一个，且不要放在副歌落点。

## 8. 遥条辙 · ao / iao

- **1声** 高 招 超 标 飘 漂 交 郊 浇 消 销 烧 抄 包 刀 掏 抛 腰 邀
- **2声** 遥 桥 潮 朝 曹 毛 苗 描 条 调 聊 疗 劳 牢 逃 桃 淘 豪 毫 谣 摇
- **3声** 小 老 了 好 早 草 找 少 倒 岛 讨 脑 恼 巧 咬 表 角 脚 晓 鸟 跑 秒
- **4声** 笑 掉 叫 到 道 报 抱 票 料 照 兆 造 噪 冒 帽 耀 药 要 绕 闹 貌 妙 庙 哨 绍

**气质**：悠扬、敞亮、有飘扬感。适合民谣、思乡、开阔的抒情。
注意「了」是助词，做韵脚会显得偷懒，慎用。

## 用韵禁忌速查

1. **不要在中途换韵——"中途"指段内**。段内跑韵是真问题；**段间换韵是国语流行的多数做法**。
   语料实测（n=487，分层样本逐首读）：**换韵 51%**、一韵到底约四成、完全不押 9%；
   说唱换韵 75%（n=100）、粤语 33%（n=36）。**"一韵到底"是选择，不是默认。**
   合规的换韵位：主歌→副歌、Bridge、按视角换（物象层 / 人称层 / 动作层）。
   唯一判据是**有意的设计**还是**撞不到韵就换**——前者要能说出理由。
2. **相邻两行不用同一个韵脚字**。
3. **同一个字全篇最多押两次**，且要隔开至少一整段。
4. **押韵位声调尽量统一**——平仄乱跳会让演唱听起来"不顺"，即使韵母相同。
5. **上声（3 声）字别放在长音落点**。三声先降后升，拖长音极难控制。
6. **助词慎做韵脚**（了 / 的 / 着 / 吗）。它们省力但廉价，用的是节奏不是内容。
7. **虚词填充要警惕**。「心 / 痛 / 爱 / 泪 / 梦」这类字做韵脚，
   十个写词人九个用，用它就是承认自己没找到更好的字。

## 需要更大字库时

`ImproAnt/high-rhythm`（MIT）提供 32 万条双押词（1,337 个韵组）、12.6 万条四押词、
单押词表，按韵母组合索引，并自带 CLI 可直接生成带押韵约束的提示词：

```bash
python3 rhyme_output_package/rhyme_toolkit.py build
python3 rhyme_output_package/rhyme_toolkit.py prompt \
  --scheme ABAB --labels A=ang+uai B=an --theme "夜晚城市" --lines 8
```

说唱 / 需要密集双押时，这个库比手查韵表有效率得多。
