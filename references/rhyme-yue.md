# 粤语（Cantonese）韵部速查

> **粤语不能用普通话十三辙。** 粤语九声六调、韵母系统独立，押韵必须按粤语韵部判。
> 音标用 Jyutping（数字为声调）。写粤语词时读这份，不要用 `rhyme-zh.md`。

---

| 中入 | 8 | 33（短） | 八 baat3、接 zip3 | **短促，绝不可拖长** ❌ |
| 阳入 | 9 | 22（短） | 十 sap6、月 jyut6 | **短促，绝不可拖长** ❌ |

**两条铁律**：
1. **入声（7/8/9）绝不可放在长音拖尾位**，尤其不能作韵脚。粤语入声以 -p / -t / -k 收尾，
   短促到没有拖音空间，写在长音位上必翻车。
2. **阴上（2）、阳上（5）慎作句尾长音韵脚**。升调拖长会持续上行，听感躁。
   情绪需要"不甘 / 上扬"时可用，其余情况优先选 1 / 3 / 4 / 6。

## 四、选韵决策表（按情绪挑韵部）

| 想表达 | 推荐韵部 | 理由 |
|---|---|---|
| 深情、缠绵（情歌主韵） | **ing**（情聲明定） | "情"字天然在此韵，题眼与韵脚重合；-ng 共鸣好 |
| 挽留、不舍 | **oi**（愛開來海） | "愛"在此韵；开口音，拖得住 |
| 伤痛、告别 | **ung**（痛夢風空） | 情绪词库密集：痛 / 夢 / 風 / 空 / 終 |
| 眼泪、离别、醉 | **eoi**（淚去醉退） | "淚 / 去 / 退 / 醉 / 句"全是分手核心词 |
| 想念、深情 | **oeng**（想長上樣） | "想"字在此韵，且可选字极多 |
| 温柔、眷恋 | **yu**（書住如雨） | 音色柔，适合低吟段 |
| 决绝、遗憾 | **yun**（願完遠段） | "願 / 完 / 段"适合收束句 |
| 明亮、昂扬 | **ong**（光望講房） | 开口大，适合副歌拔高 |
| 回忆、叙事 | **an**（人新分近） | 适合主歌叙述 |

**最热门三韵**：`ing` / `oeng` / `oi` —— 粤语情歌里出现频率最高，字库也最够用。

## 五、用韵禁忌

1. **入声作韵脚** —— 最严重的错误，拖不了长音。看到 -p / -t / -k 收尾就要警觉。
2. **阴上（2）作副歌末句韵脚** —— 35 升调拖长会一路上行，收不住。除非有意要"不甘"的效果。
3. **ing 与 ung 混押** —— 都是 -ng 尾，听感接近，但**在传统粤语词里属不同韵部**，不可混。
   （现代流行曲偶有近韵互押，但正式创作应同韵到底。）
4. **in 与 yun 混押** —— 同理，"見/前/天"与"願/完/遠"不可混。
5. **只用单韵到底** —— 全曲一个韵会疲劳。**粤语语料换韵占 33%（n=36）**，
   比国语（51%）低，但仍占三分之一——说明"一韵到底"在粤语里更常见，却也不是唯一做法。
   Bridge 是法定换韵位（换韵再回来，形成听觉弧线）。判据与国语一致：
   **段内必须统一，段间换韵要说得出理由**（换视角 / 换能量 / Bridge 转向）。

## 六、协音（melodic contour matching）

**粤语填词比普通话多一道关，也是最重要的一道。**

字的声调走向必须与旋律走向一致，否则唱出来会变成另一个字。这不是"不好听"的程度问题，
是**语义直接跑偏**的问题。

没有旋律时的近似处理：
- 句内声调要有起伏，避免连续三个同调字；
- 韵脚尽量落平声（1 / 3 / 4 / 6）——平声可自由拖长，不撞旋律走向；
- 分词节奏规整（4+6 / 4+7 / 3+7），便于旋律对位。

**拿到旋律后必须复核协音**，这是粤语词定稿前的最后一道关，优先级高于押韵。

## 七、粤语特征字（顺带解决演唱引擎识别）

唔 / 嘅 / 咗 / 係 / 冇 / 咁 / 喺 / 佢 / 哋 / 睇 / 嘢 / 俾

> ⚠️ **「都」「點」不计入**（2026-09-12 修正）——它们的字形与通用中文完全重合，
> 普通话同样在用"都""点"，计入必然误判。口径：**只计字形上就能辨识是粤语的字**。
> 实测：初版把 6 个"都"算进去，得出"10 处、严重超标"的错误结论，
> 剔除后实际 4 处（唔 1 + 嘅 3），正好达标。

**适度的粤语特征字能让演唱引擎识别为粤语而非普通话。**
但通篇"唔啲咗"会掉档——80 年代港乐本身是文白夹杂的。
建议全曲用 2–4 处，放在情绪转折或口语化的位置。

## 八、改词速查（字数不齐 / 声调踩雷时怎么修）

修一句词，**按下面的顺序动，越靠前越好**——目的是别为了这一点小毛病把整句语义推翻。

**第 1 步：先数字数，只做加减。**
- 多 1–2 字 → 删虚字（的 / 了 / 又 / 都 / 是 / 那），通常不影响语义
- 少 1–2 字 → 加修饰字，别加新意象

**第 2 步：再看末字声调。**
末字是**阴上（2）或入声**，就落进了长音雷区。此时**不要改整句**，
优先在**同一韵部内找平声同义字**替换——这是最省的一招。

**第 3 步：最后才动句意。**

### 同韵部等义替换（最推荐）

守韵 + 换调，语义几乎不变。做法：**在目标韵部内，找与要替换的词同义的平声字**。

| 原词 | 替换 | 韵部 | 声调变化 |
|---|---|---|---|
| 情景 | **情形** | ing | 景 zing2（阴上 35↑）→ 形 jing4（阳平 21，安全） |
| 身影 | **身形** | ing | 影 jing2（阴上）→ 形 jing4（阳平） |

> 已核实：情景 / 情形、身影 / 身形 都是常见词，语义基本重合，替换后整句不改读感。
> 实例：副歌「情願留在　你轉身**的那個情景**」（12 字，末字阴上）
> → 「情願留在　你轉身**那個情形**」（11 字，末字阳平）——只动一个字，
> 字数与声调两项指标同时修好。这就是首选改法。

**不是每个词都有同韵平声近义字。** 找不到时按顺序退：
① 继续在第 1 步删/加虚字，用字数去凑；② 改动句子后段（换掉末尾词组）；
③ 接受该声调——但要确认它**不落在这一句的最长音上**。

> 判据：**先保住韵部，再保住语义，最后才动句意**。
> 改完必须回读整段——一句换了字，前后句的韵脚序列和字数都要重算。

### 常见误改

- 为了字数整齐，把一句有记忆点的说法改成通用句 → 得不偿失，宁可留 1 字误差
- 换了末字却把韵部带跑了（如 ing 换到 ung）→ 段内换辙，比字数不齐更伤
- 只改这一句，忘了这一段其它句的韵脚还得对上 → 改完必回读全段
