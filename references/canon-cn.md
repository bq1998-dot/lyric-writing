## 0. ★★ 元动作：一切都是"翻译"

三批 30 首读下来，出现频率最高、也最本质的动作只有一个：

> **没有一个词是直接写情绪的。每一个情绪都被"翻译"成另一个系统里的具体物。**

`A1`（借整套词汇）、`B5`（不可见物交给可见动作）、`C1`（翻译成流程）、`C3`（翻译成身体载体）、
`C4`（翻译成权利）、`C5`（翻译成量的不足）——**它们全都是同一个元动作的不同落点。**

### 翻译的七个落点（可直接当菜单用）

| # | 落点 | 范例 | 什么时候用 |
|---|---|---|---|
| **1** | **翻译成一件实物** | 宿命 → **掌纹**；等待 → **釉色** | 情绪需要一个"能看见"的载体 |
| **2** | **翻译成一个动作** | 距离 → **被风吹远**；疏离 → **进不去的轨道** | 情绪需要"发生"而不是"存在" |
| **3** | **翻译成一套手艺/学科的词汇** | 感情 → **制瓷工序**；陪伴 → **天体运行** | 题材复杂、需要系统感 |
| **4** | **翻译成一个日常制度/流程** | 等待爱情 → **排队领号** | 要写出"被安排、身不由己" |
| **5** | **翻译成一项权利/资格** | 错过 → **失去为你哭的权利** | 要写"回不去了" |
| **6** | **翻译成一个身份/职业**（须**结构同构**） | 现代人的困境 → **模特** | 主题是某种"处境" |
| **7** | **翻译成一个量的不足** | 爱之深 → **时间不够证明** | 要写"程度之高" |

**操作三步**：
① 写下你要写的情绪（孤独、错过、等待、不甘…）；
② 问 **"它在哪个系统里有一个对应物？"**——优先选**非文学、非抒情**的系统
（制度、流程、职业、学科、身体、度量）；
③ **用那个系统的东西替换掉情绪词**，情绪词一个都不留。

**判据一句话**：**把全词的情绪形容词划掉，剩下的句子还站得住吗？**
站得住，说明你已经翻译过了；站不住，说明你在裸写情绪。

> ★ **为什么这是元动作**：它同时解释了 `ai-tell.md` 第 1 条（抽象名词）与第 4 条
> （没有具体细节）——**裸写情绪就是抽象名词的来源，翻译就是具体细节的来源。**

## 3. C1–C10（第三批新增）

### C1 · 把抽象处境翻译成一个日常制度/流程
- **操作定义**：等待爱情 → **排队领号**。抽象处境换成**城市生活里的一个具体流程**
  （排队、挂号、登记、叫号、抽签），流程自带"被安排、不知何时轮到我"的无奈。
- **判据**：**这个处境有没有一个"社会生活里的对应流程"？**
- **出处**：遇见
- **落地**：见 §0 落点 4。

### C2 · ★ 不可靠叙述者：表层与真实相反
- **操作定义**：叙述者嘴上说的和事实相反，**听众必须解码**。全曲有一个"表层意思"
  和一个"真实意思"，两者相反。
- **判据**：**如果把每句话按字面理解，会不会得出一个和主题相反的结论？** 会，就成立。
- **出处**：说谎（全曲 42 句，男主说"我没有说谎"，但从第一句起就是谎）
- **落地**：★ **30 首里结构最精巧的一首，也是最难的一条。**
  前提是**篇幅要够**（装置需要空间展开）；短歌慎用。与 `B3`（悖论标题）不同：
  B3 是**标题与正文**的张力，C2 是**正文与事实**的张力。

### C3 · 给抽象概念找一个"身体上的具体载体"
- **操作定义**：宿命 → **掌纹**；老去 → **白发**；时间 → **皱纹**；劳累 → **老茧**。
  抽象概念落在一个**身体部位上的实物**。
- **判据**：**这个概念能不能长在身体上？**
- **出处**：流年（「手心忽然长出纠缠的曲线」）
- **落地**：与 `B5` 分工——**B5 是给抽象物配一个可见动作（动态），C3 是给它找一个身体载体（静态）**。
  两个一起用最有效：**载体 + 动作**（掌纹**长出**、皱纹**爬**上来）。

### C4 · 把情绪翻译成"一项权利/资格的得失"
- **操作定义**：错过 → **失去为你哭的权利**。把情绪表述成**一种资格的得失**，
  比"我很难过"高一个层级。
- **判据**：**这份情绪能不能被表述成"我还有没有资格做某件事"？**
- **出处**：小幸运
- **落地**：见 §0 落点 5。**写"回不去了"时最有效**——"回不去"的本质就是"没资格了"。

### C5 · 用"不够/来不及"来写"太"
- **操作定义**：不说"太深"，说**"时间不够证明"**。**通过量的不足来写质的高。**
- **判据**：**这句是在形容程度，还是在说"量不够"？** 说"量不够"更高级。
- **出处**：贝加尔湖畔（「这一生一世 这时间太少 不够证明融化冰雪的深」）
- **落地**：同类写法：来不及、装不下、数不完、说不完。**适用于写"浓烈到无法计量"的情感。**

### C6 · 排比的排列顺序本身是一条曲线
- **操作定义**：各项**不是并列**，而是沿一条线滑动——从自夸一路滑到自嘲，
  **顺序承担意义**。
- **判据**：**把各项顺序打乱，意思变不变？** 变了说明顺序在承担意义。
- **出处**：像我这样的人（"像我这样 X 的人"从"优秀"滑到"莫名其妙"）
- **落地**：★ 这条**直接改写了 `A3` 的判据**，见 §4 修正 1。

### C7 · 标题双关：一个词的两义同时运行
- **操作定义**："流年"既是**时光**也是**命理里的运势**，全曲两个意思都成立。
- **判据**：**标题的第二个意思，在正文里是不是也全部成立？**
- **出处**：流年
- **落地**：与 `B3`（悖论标题）区分——**B3 是矛盾，C7 是叠义**。
  做法：挑一个**本身就有两个义项**的词当标题（流年、因果、结、局、瘾、岸）。

### C8 · 语调本身承担内容
- **操作定义**：写"被定义"的困境，就用**冷峻、描述性、无温度**的语言；
  不抒情、不评判。**语调与主题同构。**
- **判据**：**把这句词的情绪色彩拿掉，语调还和主题一致吗？**
- **出处**：模特
- **落地**：★ 三批 30 首里**只有这一首把语调当内容**——说明它是最稀缺的一条。
  对照：写温柔就用温柔的语言（`B1` 的"说话行为"是同一思路的语言层版本）。

### C9 · 借一个"结构同构"的身份/职业当隐喻
- **操作定义**：模特"被观看、被定义"的结构，与现代人在社会里的处境**同构**，
  所以整套词汇直接可用。**借的不是词汇，是结构。**
- **判据**：**这个身份的内在结构，和主题的结构是不是同一副？**
- **出处**：模特
- **落地**：★ 这是 `A1` 的**更精确版本**——`A1` 说"借一套词汇"，C9 说清**为什么能借**：
  **因为结构同构**。借之前先验证同构，否则词汇会打架。

### C10 · 用无意义音节承担说不出的部分
- **操作定义**：该说的地方**留白**，用"啦……""嘿""哦"填。**用无词的音乐段落
  承担语言说不出的部分。**
- **判据**：**这一段是不是"说不出来"的？** 是就用音节，不要硬写词。
- **出处**：那些花儿
- **落地**：★ 与 `A4`（结尾不给结论）配合——**结尾落"啦"是最彻底的"不给结论"**。
  ⚠️ Suno 场景下要注意：无意义音节**可能被模型当成歌词唱成怪音**，
  交付时在 Style 里写明 `hummed outro` / `wordless vocalise`。

### C 补 · 六条较轻但可用的动作

| 动作 | 判据一句话 | 出处 |
|---|---|---|
| **意象故意模糊、不说破**（一个开放物指代一切） | 这个意象全曲有没有被定义过？定义了就是失败 | 那些花儿（"花儿"） |
| **极简比喻：本体喻体共用一个动作** | 这个比喻需不需要解释？需要就是太复杂 | 七里香（"我的爱溢出就像雨水"） |
| **用与主题无关的日常细节开场** | 第一句有没有直接点题？点了就换个细节 | 七里香（"窗外的麻雀 在电线杆上多嘴"） |
| **用自嘲而非控诉写不甘** | 这句是在控诉别人，还是在嘲笑自己？ | 像我这样的人 |

## 4. ★★ 五处判据修正（**优先级最高**）

**动作可以晚点看，这五处改的是既有规则。**

### 修正 1 · 排比判据：从"类型表"改成"通则"

| | 内容 |
|---|---|
| **原始判据**（第一批） | 合法排比只有**两种**：对立式（敬朝阳／敬月光）、动作式（爱你走暗巷） |
| **第二批补一条** | 加入第三种：**关系模式式**（"我怀念的是无话不说"——关系里的一种持续相处方式） |
| **第三批发现** | 还有：**顺序成曲线式**（"像我这样 X 的人"从自夸滑到自嘲，**顺序承担意义**） |
| **问题** | **按类型枚举永远列不完。** 每遇到一首新歌就要加一条，判据会越写越松 |
| **★ 最终判据** | **不看"属于哪一类"，只看"项与项之间有没有一个可命名的关系"。**<br>有 → 合法（对立 / 动作 / 相处方式 / 递进曲线 / 同一对象的不同切面 / 顺序成曲线…）；<br>**没有 → 非法。同义并列（梦想、远方、自由）＝项与项之间没有任何关系。** |
| **为什么这样改才对** | 原判据会把"我怀念的是无话不说"误判为非法——**它是那批词里最好的句子之一**。**判据太窄会把好句子当病句杀掉；枚举式判据还会越列越松。通则才稳定。** |

### 修正 2 · `ai-tell.md` 第 1 条：抽象名词**看谓语，不看个数**

| | 内容 |
|---|---|
| **原判据** | 单行/单联出现 **≥3 个抽象名词**即标危 |
| **反例** | 「**梦**为**努力**浇了水 **爱**在背后往前推」——一行全是抽象名词，**却毫无 AI 味**，因为每个抽象词都做了一件具体的事 |
| **★ 修正后** | · **抽象名词 + 具体动词**（只有实物才做得出的动词：浇、推、私有、抵押、搬走）＝ **合法，甚至高级**<br>· **抽象名词 + 抽象动词**（闪耀、永恒、绽放、升华）＝ **危**<br>· **≥3 个只作粗筛，不作判罪依据** |
| **为什么要改** | 原判据是**数量判据**，会误杀"梦为努力浇了水"这种高级句，**同时放过"梦想闪耀"这种真正的 AI 味**（后者抽象词不到 3 个，根本查不出来）。**已直接改入 `ai-tell.md`。** |

### 修正 3 · "不给结论"不只适用于结尾

| | 内容 |
|---|---|
| **原判据** | 全曲**最后一行**不许给结论 |
| **反例** | 「她**开始明白**等待未必有结果」——**在段中**就把"转变"停在起点上，不写结果 |
| **★ 修正后** | **全曲的每一个"转变"，都只写它开始的那一刻，不写它的结果。** 结尾只是最显眼的一处应用 |
| **判据** | **这一句是"开始 X"还是"因为 X 所以 Y"？** 出现"所以""从此""终于明白…于是"就是给了结论 |
| **为什么要改** | 原判据只管最后一行，等于**允许中间每段都把情绪走完**——那正是 `ai-tell.md` 第 3 条"什么都解决了"的来源 |

### 修正 4 · `A1`「借一整套词汇」**有适用边界**

| | 内容 |
|---|---|
| **原表述** | 借一整套专业词汇写感情（越"不文学"的来源域越好） |
| **反例** | 《七里香》「雨下整夜 我的爱溢出就像雨水」——**不借任何域，只借一个动作**，同样高级 |
| **★ 修正后** | **`A1` 不是"更高级"，只是"更系统"。两条路等价，按题材选：**<br>· 题材**复杂、需要系统感** → 借整套域（青花瓷、水星记）<br>· 题材**单一、情感浓烈** → **极简比喻**（本体喻体共用一个动作），**复杂化会稀释它** |
| **判据** | **这个比喻需不需要解释？** 需要 → 你在用 `A1`，那就要把整套域都搬来；<br>不需要 → 用极简比喻，**别再往上堆东西** |
| **为什么要改** | 原表述容易被读成"越复杂越高级"，会诱导出**典故堆砌**——那正是 `A1` 最常被误用的方向 |

### 修正 5 · `A4` 的合法结尾形态是**五类**，不是三类

| | 内容 |
|---|---|
| **原判据** | 结尾落**动作 / 静物 / 问句** |
| **第三批补充** | 还有两类：**无意义音节**（那些花儿"啦……"）、**悖论句**（消愁"清醒的人最荒唐"——**悖论句是"结论"的唯一合法形态，因为它不给答案**） |
| **★ 修正后** | 五类：**动作 / 静物 / 问句 / 无意义音节 / 悖论句** |
| **判据** | **最后一行是"我说完了"还是"画面停住了"？** 五类都算"停住" |
| **附带统计** | **三批 30 首里没有一首以"陈述式结论句"收尾**——这条不是偏好，是硬事实 |

### 修正 6 · 周传雄范式：立意方法三特征（2026-09-29 新增）

**适用条件**：写"承认/承认不够/承认到了但还差一截"的情绪题时，**30 首经典方法论不够用**——
青花瓷/消愁/富士山下都能写出"承认"，但**周传雄范式是把承认拆得更狠**。
参考样本：《我的心太乱》（一句对型，认罪不认爱）、《寂寞沙洲冷》（双状态叙述，问题作承认）。

| 特征 | 原文示例 | 判据 |
|---|---|---|
| **① 承认时刻认罪不认爱** | 「如果爱情不如我们想象的甜美 / 那么所有的罪让我来背」 | 承认时刻落 **事实 / 责任 / 罪**，**不落**情绪词「爱/思念/痛」。**自我写词最易翻车的位置是"承认时刻落到情绪上"**，这一节把承认时刻从正向减负 |
| **② 承认句可以问，不答** | 「寂寞沙洲我该思念谁」 | 承认句用**问题**不用答案——「我该思念谁」= 承认想念，但**拒绝回答想念谁**。**不答比答了更真**。当整首无法找到一个简短的承认判语时，**承认作问**比硬写"我爱他"高一档 |
| **③ 双状态对位** | Pre-Chorus：「有花儿伴着蝴蝶 / 孤燕可以双飞 / 夜深人静独徘徊」+「红色分享喜悦 / 闭上双眼难过头也不敢回」 | **用 4 组对位把"在场/缺席"的对比拉满**：花/蝶/双燕/分享喜悦 ↔ 无花/无蝶/独/闭眼。**风景有陪 ≠风景在场**——外部"有"把内部"无"顶出来。**这是周传雄的"不写我状态，写别人有"的技巧**，是 §0「翻译」元动作的分支 |
| **④ 病状化型过渡** | 「是黄昏占据了心扉」 | 一句对型向病状化型的过渡标记：**抽象物（黄昏）作为施事者 + 侵入动词（占据）+ 身体部位（心扉）**。**情绪不直接出场，让抽象物替你"占据"身体**——与 § 0 「翻译」互补：§ 0 是把情绪翻译到物件，④ 是把物件当作施事者回写到身体 |
| **总体使用顺序** | 立意定题型（一句对 / 双状态叙述 / 病状化）→ 选特征（认罪不认爱 vs 问题作承认）→ 写主歌（物件+动作+时空）→ 写副歌（承认句/问句）→ Bridge（病状化或两态并列） | 经典三阶段对应骨架——一句对型用 ①、双状态用 ②③、病状化用 ④ |

**判据一句话**：周传雄范式最危险的反模式是"承认时刻落在情绪词上"——这是自我写词最容易栽的根，
**这五条铁律就是给这种时刻划红线的关键**——边缘三处全部由"事实/问句/抽象物施事"承担。

## 7. 写中文词时的执行顺序

```
① 定题与道具        → SKILL.md「道具锚定」（定那一件事 + 贯穿道具）
② 定说话行为        → B1：这首歌在做一个什么说话行为（劝/答/告解/告白）？
③ 做翻译            → §0 元动作：把情绪翻译到七个落点之一（优先非文学系统）
④ 选来源域          → A1 + C9：挑一门手艺/学科/制度/职业；**先验证结构同构**
⑤ 定视角与那一跃    → A9 + B9：说话人站在哪；第三人称？末句收回为"你"？
⑥ 排比先定关系      → A3（通则）：先定项与项之间是**什么关系**，别写着看
⑦ 写主歌            → 景为主；每段至少一处"物+活动词"（A8）；不可见物交给可见动作（B5）
⑧ 写副歌            → 格言必须有说话人（A2）；大词用生活物接住；抽象词配具体动词（B2）
⑨ 定结尾与转变      → A4（五类）+ 修正 3：每个转变只写"开始"那一刻
⑩ 降级替换          → A5：书面词换口语词，加口语虚词与叠词做呼吸（B10）
⑪ 夹心收口          → A10：情的部分删到一句
⑫ 跑合规与终检      → verify_zh.py + 13 项自检 + ai-tell.md（注意修正 2）
```
