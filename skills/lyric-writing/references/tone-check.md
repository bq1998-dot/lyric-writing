# 倒字检测：普通话「字调 × 旋律」冲突

> 适用：**普通话**歌词，且已知（或可推断）旋律走向。
> 粤语另有协音规则，严得多，**不能用这一套顶替**（见本文末）。
> 来源：方法吸收自 MIT 项目 `jtydhr88/lyric-writing-skills`（作者 Terry Jia）的
> `lw-tone-check` / `lw-mandarin`，其声律依据可追溯到赵元任五度标调、
> 王力《汉语诗律学》与黄志华《文字声律与粤语歌创作》所引薛範八条。本文件为**改写重述**。

---

## 1. 是什么问题

普通话每个字有**调型**。旋律在字与字之间的走向，如果和调的高低关系相反，
听感上字就变了：

> **「深爱」(shēn ài) 唱成「神爱」(shén ài)。**

戏曲里这叫**依字行腔**，是同一个问题的老版本。

---

## 2. ★ 正确模型（大多数人的第一直觉是错的）

**判的是「进入这个字的音程」 vs 「这个字自身的调型」**，
**不是**「前字终点 vs 后字起点」的相对高度。

```
contour  = 本字调型（+升 / −降 / 0平）
incoming = 进入本字的音程（半音）
```

### 为什么相对高度模型是错的

按相对高度判，会**漏掉教科书上最经典的例子**：
**「深爱→神爱」算出来的期望是 +0，永远不会被标记。**

原因是流行歌**一字一音是常态，字内没有调型可言**——
这时候听者是从**进入这个字的旋律走向**去推断它是什么调。
**上行进入「深」（阴平，平调），就听成了阳平 = 神。**

★ **一条通用教训**：**当检测器测不出教科书上的标准案例时，先怀疑模型，不要怀疑案例。**

---

## 3. 五个调与它们的约束

赵元任五度标调，取每个调的**起点**与**终点**：

| 调 | 五度值 | 调型 | ★ 约束 |
|---|---|---|---|
| **阴平** 1 | 55 | 平 | **进入它不该有大跳**（大跳会把平调听出走向） |
| **阳平** 2 | 35 | 升 | ★ **不该下行进入** |
| **上声** 3 | 21 | 降 | 不该上行进入（连读取**半上**；全上 214 只在单念和句末） |
| **去声** 4 | 51 | 降 | ★ **不该上行进入** |
| **轻声** 5 | ~3 | 平 | 同阴平，**但权重减半**（本来就轻、短、易被吞） |

> ★★ 这正是老话说的 **「阳平字别配下行、去声字别配上行」**。

---

## 4. 没有检测器时怎么手判

只查**三类位置**——它们是倒字最常发生的地方，约占全部字的 **1/5**：

1. **每段最高音的那个字**
2. **每句的第一个字**
3. **大跳（≥5 半音）的落点字**

对每个字：查它的调（§3 表）→ 看进入它的旋律方向 →
**阳平被下行进入 / 去声被上行进入 / 平调被 ≥3 半音大跳进入** → 标风险 → **念一遍**。

---

## 5. 风险计分

| 列 | 含义 |
|---|---|
| **调型** | 本字自己的调要求什么走向（升 / 降 / 平） |
| **进入** | 实际的旋律走向（半音） |
| **风险** | 0–1。**跳得越大风险越高** |
| **倒字率** | 有风险的相邻字对 / 总对数 |

**三条计分规则**：

- 升调被下行进入、降调被上行进入 → 风险 = `min(|interval|, 12) / 12`
- **平调被 ≥3 半音的跳进入** → 风险 = 量级 **× 0.8**
- **轻声** → 风险再 **× 0.5**

示例输出：

```
我深爱你   —— ★ 教科书例：上行大跳进入平调「深」→ 听成「神」
  倒字率 33%  （1/3 对相邻字有风险）
  字      调型    进入    风险   说明
  深       平    +7    0.47 ← 阴平是平调，7 度大跳会带出走向
  爱       降    -2    0.00
  你       降    -1    0.00
```

## 6. ★★ 三条边界：别把这个检测器当判官

**这一节是本文件最重要的部分。**

### 6.1 一字多音（拖腔）没处理
本方法**假设一字一音**。一个字拖多个音时，**字内轮廓本身就能承载调型**，规则不同。
★ 后果：**慢歌、抒情曲、戏曲风的段落会误报。**

### 6.2 不看语境消歧
> **「深爱」在「我深爱着你」里几乎不会听错，因为上下文锁死了词。**

本方法只看声学层面的风险，不懂词。★ 后果：**常用搭配、成语、固定词组会被误报。**

### 6.3 ★ 倒字风险 ≠ 错
**长音、重音、清晰咬字都能救。输出的是「风险」不是「判决」。**

### 6.4 综合起来怎么用

> ★ **把它当成一支荧光笔，不是一个判官。**
> 它告诉你"这几个字值得念一遍听听"，**念了没问题就放过**。

**自检动作**：
1. 跑检测 → 得到高风险字清单
2. ★ **把那几句唱出来**（或念出来）
3. 真的听成别的字 → 改（§8）；听不出来 → **记一句「已人工确认」**

## 7. 从严 / 从宽：哪些必改，哪些可以放过

### 7.1 从严三条（落在这三条里，必改）

1. **与口语结合紧、语感强的作品从严**——流行歌曲、说唱一类（几乎覆盖全部创作场景）
2. **主题句、高潮句、关键词、结尾句从严**——位置不高、不跳，但它是 hook，要单独加查
3. **前后紧挨的两个音音程大、呈上下行跳进的从严**——与 §4 的「大跳落点字」同一条

### 7.2 从宽五条（落在这些里，可放过并记一句理由）

| # | 从宽 | 为什么 |
|---|---|---|
| 1 | **弱拍上的语助词、虚字、轻读字** | 听众本来就不在那里辨字 |
| 2 | **节奏短急且旋律平稳或级进的；或节奏舒缓、拖腔抒情的** | 前者字过得太快，后者长音能把字调唱回来 |
| 3 | **单个字**（不是双字词组、不是四字成语） | 没有前后字给它定调，误听空间小 |
| 4 | **反复咏唱的词语，只要有一次是正字** | 听众已经在前面记住它了 |
| 5 | **分节歌的个别处**（一段旋律配两段以上的词） | 绝大多数做到正字即可，个别处宽大处理 |

**用法**：先标风险位，再拿这五条逐个问。**落在五条之内的放过并记理由，落在从严三条之内的必改。**

---

## 8. 标出风险了，五种改法（按代价从低到高）

| # | 改法 | 代价 |
|---|---|---|
| **1** | **换字** | 最低。同义词里找一个调型顺的 |
| **2** | **调整词序** | 低。把那个字挪到旋律走向合适的位置 |
| **3** | **给那个字加时值**（拖长） | 中。★ 拖长之后字内可以自己走出调型，风险消失 |
| **4** | **改旋律的那一跳** | 中高。★ **先曲后词时这是最后手段**；先词后曲时它是正常选项 |
| **5** | **接受它** | ——但要在交付文档里**写明理由**（如"这里刻意的错听是个双关"） |

★ **第 1 条永远先试。** 中文同义词极多，换个字通常就解决了，改旋律会牵动其他所有设计。

★★ **第 5 条不是偷懒**：真实的流行歌里有大量"技术上倒字但听起来没问题"的地方。
**关键是你知道它在那儿，而不是没检查。**

## 9. 普通话句尾平仄（唯一的硬用法）

**流行歌词不排平仄格式**，三本主流教材都不给歌词开平仄谱。
平仄**只有一条硬的、可操作的用法**：

> **「在两句成双的唱词中，平声字用于下句，仄声字用于上句。」**

**为什么成立**：平声**没有升降、较长** → 适合拖住、收住；
仄声**有升降、较短** → 适合悬着、催下一句。

| 位置 | 用 | 听感 |
|---|---|---|
| **上句尾**（问、起、未完） | **仄** | 悬着，要下句来接 |
| **下句尾**（答、收、段落结束） | **平** | 落定，能拖长 |

★ **合起来用**：**段落最后一个字的最优解 = 平声 ＋ 开口音**（既拖得住，又唱得响）。

**失效条件**：
- **先曲后词**时旋律收束形态已定，这条只能用来**挑字**，不能用来改句
- **粤语无效**
- 故意要"停在难受里"的段落，**上句的仄声尾就是对的**，不要收平

**自检动作**：把每段的**最后两句尾字**标出平仄。下句尾是仄声而这段又是收束段 → **念一遍**，
听着是不是没落地；是的话换字。

## 10. 一字两读：写词时必须先定读音

同一个字有两种意义、往往词性也不同时，会有两种读音：

| 字 | 平声时 | 仄声时 |
|---|---|---|
| 为 | 动词 | 介词（去声） |
| 思 | 动词，思念 | 名词，思想情怀（去声） |
| 骑 | 动词，骑马 | 名词，骑兵（去声） |
| 教、令 | 动词，使、让 | 名词，教化／命令（去声） |
| 看、望、叹 | 本读平声 | 后变去声，**意义词性不变** |

★ **这不是考据，是倒字检查的前提**：**同一个字读阴平还是去声，调型完全相反。**
你在词里写「思」，是名词还是动词，决定了它该配什么走向的旋律。
**自检动作**：词里出现这类字，在交付文档里注明读音；不注明，检测会判错。

**两条省事的辨别法**：
- 「凡**韵尾是 -n 或 -ng** 的字，不会是入声字」
- 入声问题是辨别平仄的**唯一障碍**——查表即可

## 11. 粤语：不是这一套

★ **粤语的协音是另一回事，严得多。**

| | 普通话倒字 | 粤语协音 |
|---|---|---|
| 声调数 | 4（+轻声） | **9** |
| 约束强度 | **风险**（可救） | ★ **硬约束**（违了就是错字） |
| 写作顺序 | 词曲都可以先 | ★ **旋律先定**，每个位置只剩几个字可选 |
| 判法 | 本文 §4 手判 | 见 `references/rhyme-yue.md` 的协音规则 |

**不要用普通话那套顶替粤语。**
