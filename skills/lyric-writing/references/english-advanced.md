# 英文进阶规则：Hook 落音 · 低音配额 · 元音动作 · 句长

> **写英文词必读。** 这里放的是「低音炮 / Hook 落点」的完整设计法，
> 以及两条容易被忽略的细节错。
> 基础韵法与重音规则见 `SKILL.md` 的「### 英文」1–5 条。

---

6. **Hook 落点的元音设计——"低音炮"歌的第一性约束**（2026-09-13 新增）。
   用户要"低音炮 / 极低音 Hook"时，**要改的不是词，是"哪一句落低音"**。
   发声物理：嗓音下潜时口腔必须张开，**深低音只能落在暗色开元音上**——
   /oʊ/（low, home, alone, go）、/ɔ/（all, long）、/ɑ/（heart, dark）、/u/（you, blue）；
   落在**前元音**上（/æ/ man、/i/、/ɪ/ hear）必然挤、发紧，出不来光泽。做法三条：
   ① **找钱音（money note）的落点**：把行末字换成暗色开元音，且让该行**有足够长度**
      供旋律下行（长行在此时是优点，不要为整齐把它砍短）；
   ② **做成同族对句**——相邻两行都收在同一暗色韵上（如 go / low），
      这样旋律下行时**有两个连续落点**可放低音，不靠赌一个字；
   ③ **明令禁止前元音落点下潜**，并在交付文档里点名它是"旋律的高解决"——
      **有了高处的对照，低处才显得低**。全曲最后一个音也尽量收在暗色元音上（有始有终）。
   实证：Josh Turner《Your Man》的低音落在 "…turn the lights down **low**" 与
   "soft and **slow**"（两句都是 /oʊ/）；标题句 "just to be your **man**"（/æ/）
   落的是**中音区**——它是高解决，不是低音。
   **连带结论：一首"低音炮"歌需要两个 Hook 分工**——**音符 Hook**（那记沉下去的音，
   落在暗色开元音）+ **短语 Hook**（那句身份句，中音区解决）。混在一句上必然牺牲一个
   （常见症状：把身份句当成低音 Hook 去加粗强调，而那句的落字恰是 /mæn/——
   全曲最不适合下潜的字）。**元音能量 > 韵脚纯度**——
   为凑完美韵把 "man" 换掉，身份句就没了，这种情况宁可留 slant 韵。
7. **两条最容易被忽略的细节错**（2026-09-13 新增）：
   ① **主歌内时态漂移**——英文歌词极易在一条主歌里从现在时滑到过去时再滑回来
      （常见形态：V1 现在时 → V2 开头 `I set / watched` 过去时 → V2 后半 `could lift`
      又滑回现在）。朗读一遍就听得出来，**交付前必查自检第 8 项**。
   ② **同一段内某个实词作韵脚出现两次**（原稿 V2 的 `rain` 两次都在句尾）——
      英文不如中文显眼，必须让脚本按**行末词**统计。中文那条
      "同一个字最多押两次"的规则，在英文里同样成立。**同样先折叠重复段落**——
      副歌照抄各遍会让同一个行末词反复出现，那不是复押。
      ⚠️ **折叠要用显式的 `seen` 集合，别用 `if key in flat` 这类写法**（`flat` 是字符串列表、
      `key` 是元组，恒不相等，等于没折叠）。
      ⚠️ **更隐蔽的是反向的坑：用 dict / set 做聚合会把重复段静默吞掉。**
      实测：一个 59 词的稿子（含三遍副歌）用 `sum(WORDS.values())` 统计，
      **被算成 47 词**（三遍副歌只算一遍），行数与"平均词/行"同时失真。
      正解：**总词数按行累加** —— `sum(WORDS[l] for l in all_lines)`，
      并把"去重后词数"单独报出来当参考值。
      凡是用 dict / set 聚合的统计项（词数、行数、行尾词计数），
      交付前都问一句 **"重复段会不会被吞掉"**——**错的脚本比没有脚本更危险。**
8. **低音配额：低频是配额，不是弥漫气氛**（2026-09-17 新增，第 6 条的第二层）。
   第 6 条解决"落**哪**"，这条解决"落**几次**"。做了第 6 条之后极易犯的错是——
   **主歌也顺手落了暗色开元音**，结果副歌那记沉音不稀罕了。
   规则：**先按曲长定低音配额，再把配额全部集中在副歌。**
   - **≥ 3 分钟**：副歌 3–4 行落 /oʊ/ + 结尾再补一个（3 分半的稿子全曲可铺 4 处）；
   - **≤ 1 分半（极短版）**：**全曲只允许副歌 2 行落 /oʊ/**，主歌一律前元音 / 中性元音
     （16 行的极短版里只放 2 行，且脚本审计主歌暗色落点必须为 0 处）。
   **同一套提示词、同一个嗓音，靠"配额"这一个旋钮就能拉开与前一稿的距离。**
   审计方式：逐行标出句尾元音，把暗色落点单独列出来数数——**耳朵听不出来，元音表一摊就露馅**。
9. **元音子类分辨：开口度大 ≠ 能唱低**（2026-09-17 新增）。
   /uː/（you / true / tune / noon）开口度确实大，但它是**高后元音**——
   男低音唱到 /uː/ 会被顶上去、顶到换声区；**/oʊ/ 是复元音滑音，可以顺势沉**。
   所以 /uː/ **不算低音落点**，不能拿来当"暗色开元音"用。
   实践做法：**/uː/ 安排在主歌与副歌前两行（中性区），/oʊ/ 全部留给副歌后两行。**
   （写"低音炮"歌时，暗色开元音的优先序是 /oʊ/ > /ɔ/ /ɑ/ > /uː/；/uː/ 是备选，不是首选。）
   **② 元音不只是音色，还是一种"动作"**（2026-09-18 新增，`suno` 灵魂蓝调稿）。
   同样在暗色开元音名单里，**动作可以完全不同**：

   | 元音 | 动作 | 结果 | 什么时候用 |
   |---|---|---|---|
   | /oʊ/ | **复元音**，能从 /o/ 滑到 /ʊ/ | **滑下去＝下沉** | 要"沉"（低音炮、慢蓝调、乡愁） |
   | /ɑr/ | 单元音 + **r 化收尾，r 把音挂住** | **能张不能滑＝悬停** | 要"停住"（soul ballad、时间静止、悬而未决） |
   | /eɪ/ | 前元音、舌位偏前 | **亮**（不沉） | 要"亮"（留恋、温柔、向前看） |
   | /aɪ/ | 开元音但极短、向外 | **压（高压平面）** | 要高能量不掉（硬摇滚） |

   **一句话：/oʊ/ 能滑，/ɑr/ 会挂。** `/ɑ/` 本来就在暗色开元音名单里，所以选 /ɑr/
   **不是"退一档的妥协"，是换了一种物理动作**——判断依据是**你要这首歌"沉"还是"停"**。
   配套设计：**家族韵铺景**（带辅音尾的 /ɑr/：dark / barn / yard / arm——落不下来）、
   **完美韵收请求**（完全开口的 /ɑr/：far / are——落地；让唯一的完美韵对只出现在 Hook 句）。
   验收：脚本逐行标行尾元音，**把"不想要的元音"也断言成 0**（如不需要低音炮时，
   行尾 /oʊ/ 与 /uː/ 必须为 0 处）。
10. **换意境 = 必须重跑落音迁移审计**（2026-09-17 新增，最难自查的一个坑）。
   用户说"意境改成 XXX"时，低音落点**必须跟着迁移**，因为**元音有语义场**：
   - /oʊ/ 的词库是 low / go / home / alone / road / gold —— 全部属于「**离开与归家**」；
   - 若新意境里没有"离开"（如"一起在溪边漫步、愿此刻永存"），硬塞 /oʊ/ 就得写
     `go home` 这类**与主题方向相反**的词（回家＝漫步结束）。
   - 替代选择：/eɪ/（stay / away）——**`Stay` 一个词就把"留"的动作做完了**。
     **代价要如实告知用户**：/eɪ/ 舌位偏前，严格说不算暗色开元音，比 /oʊ/ 浅一档。
     **补偿三招**：① 落点加量（三处而不是两处）② Hook 词重复两拍（第二遍可更低）
     ③ 末句收在该元音上（主题词与落音重合）。**并给 Plan B**（如 `away` → `alone` 即可回 /oʊ/）。
   **但真正的坑不是这个——是旧的低音字作为"景物描写"悄悄留在了主歌里。**
   实测：连改三版才清干净（v2 是 `slow` / `home`，v3 是 `slow` / `gold`，v4 才是 `low`）。
   **每一版听起来都毫无问题，元音表一摊开就连错三轮。**
   **铁律：换意境后必须重跑低音配额审计，不能靠听。**
11. **句长是独立变量，与韵部、字数都无关**（2026-09-17 新增）。
   用户说"每句话长了 / 改短"时，若当前是**慢歌**（<80 BPM），句长的杀伤力尤其大：
   8–9 词/行在 76 BPM 里每行要占 **2 小节**，句子长 → 乐句长 → 呼吸口少 → **慢歌会拖**。
   **改法不是删形容词，是换写法——"短句并置"**：
   一句一个画面，靠**并置**产生关系，不靠连接词把画面串起来。
   | 长句（解释型） | 短句（并置型） |
   |---|---|
   | Your blue scarf is hangin' on the kitchen chair (9) | Dust on the road (4) |
   | The screen door's bangin' in the evenin' breeze (8) | The river runs cold (4) |
   | Set your heavy suitcase down and let it go (9) | Stay one more night (4) |
   实测：8.8 词/行 → **3.6 词/行**，重音节 8–9 → **2–3**，每行只占 1 小节。
   **短句的连带收益**：呼吸口变多；**一个意料外的结构动作**——把最静的一行放在
   三句央求中间（"央求 / 央求 / **一个画面** / 央求"），静物被求声包住，比四句都求更有力。
12. **「某个元音不能用」往往是「某一批词不能用」，不是元音本身不能用**（2026-09-18 新增，
    第 10 条的第二层，也是最容易把结论用死的一处）。第 10 条为了避开「离开与归家」语义场，
    让上一稿从 /oʊ/ 退到 /eɪ/，并标明"接受了浅一档的开口度"。
    但**卡住它的其实只是 `go home` 那一类词**——而 `slow` 恰恰是 /oʊ/ 词库里唯一自带
    「延迟、不让时间过去」语义的字，且 `slow` 与 `go` **同韵**：
    一个说「快点过去」、一个说「慢一点」，**这个矛盾本身就是主题**。
    所以换成蓝调重写时又把 /oʊ/ 拿回来了——`Don't let go / Take it slow`，
    副歌 6 处 + Outro 1 处落点、主歌暗色落点 0 处，
    **同一个「愿时间停留」的主题第一次用上真正的暗色开元音**。
    **做法：换体裁 / 换视角时，把"被禁的那批词"重新审一遍，不要沿用上一稿的结论。**
    配套判据：一个元音能不能用，取决于**你要落的那句话在语义场里站哪一边**，
    而不取决于那个元音的音色本身。
