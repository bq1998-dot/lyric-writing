# 发音风险清单（AI 人声 / 真人演唱的双重事故点）

> 用途：**交付前逐项核**。这一类和别的错不同——**别的错是效果不对，这类是唱出来的根本不是你要的词。**
> 来源：英文同形异音表与「生造缩写」规则吸收自 CC0-1.0 项目
> `bitwize-music-studio/claude-ai-music-skills`（`skills/lyric-writer`、
> `skills/pronunciation-specialist`）；中文部分为本地既有经验整理。

---

## 一、英文：同形异音词（homograph）

**同一个拼写、两种读音，意思完全不同。** AI 人声按最常见读音唱，往往就是错的。

| 词 | 读音 A | 音标重拼 | 读音 B | 音标重拼 |
|---|---|---|---|---|
| **live** | 现场的 / 直播 | `lyve` | 居住 / 活着 | `live` |
| **read** | 现在时 | `reed` | 过去时 | `red` |
| **lead** | 引导 | `leed` | 金属（铅） | `led` |
| **wound** | 伤口 | `woond` | wind 的过去式 | `wownd` |
| **close** | 关上 | `kloze` | 靠近的 | `klohs` |
| **bass** | 低音 | `bayss` | 鲈鱼 | `bas` |
| **tear** | 眼泪 | `teer` | 撕裂 | `tare` |
| **wind** | 风 | `wihnd` | 缠绕 / 上弦 | `wynd` |

**做法（三步，全部在交付文档里留痕）**：

1. **识别**——拼音审核时逐个标出（上表是基线，不完备）
2. **定夺**——★ **按上下文自己定读音，不必问用户**（属可自定的细节）。有歧义时在交付文档的
   「发音标注」里写明取值与理由（如「此处 `live` 按 `lyve`（现场）处理」）
3. **应用**——**只改 Suno 的 Lyrics 框**；发行/流媒体用的歌词保留标准拼写

> ⚠️ 反面规则：**「上下文已经清楚了」不能当作不标注的理由**。
> 你清楚，后端不一定清楚——**标注是给生成器看的，也是给你自己复核用的。**

## 二、英文：不要生造缩写

**Suno 只认标准英语缩写。** 给名词、品牌名、非标准词硬加 `'d` `'ll`，后端会读错或直接跳过。

| | 例 |
|---|---|
| ✅ **标准，可用** | they'd · he'd · you'd · she'd · we'd · I'd · wouldn't · couldn't · shouldn't |
| ❌ **生造，会坏** | `signal'd` · `TV'd` · `network'd` · `podcast'd` · `channel'd` |

**改法**：**写全** —— `signal would` 而不是 `signal'd`；`TV could` 而不是 `TV'd`。

**判据一句话**：**基础词不是代词或标准助动词，就不要缩写它。**

## 三、中文：发音风险

### 3.1 四类高风险词

| 类别 | 例 | 处理 |
|---|---|---|
| **专有名词** | 人名、地名、品牌 | 音标重拼或改词 |
| **多音字** | 行 / 重 / 长 / 还 / 差 / 系 | ★ **必须先定读音**，见下 |
| **英文缩写** | AI / GDP / OK | 音标重拼：`AI` → `A I` |
| **自造缩写词** | 生造的中英混用简写 | 尽量不用 |

### 3.2 多音字：与「倒字」是同一件事的两面

★ **一字两读时，调型往往完全相反**——所以**定读音是倒字检查的前提**。
「为」「思」「骑」「教」「令」「看」「望」「叹」这一类，读平声还是去声，
决定了它该配什么走向的旋律。**写词时必须先在心里定下来，并在交付文档注明。**

详见 `references/tone-check.md` §10。

### 3.3 三种重拼手段

| 手段 | 例 | 用在哪 |
|---|---|---|
| **音标重拼** | `AI` → `A I`；`Potrero` → `poh-TREH-roh` | 专名、缩写 |
| **连字符断音** | `研-究` | 防止连读吞音 |
| **重复元音** | `a-a-ah` | 要拖腔时显式写出来 |

### 3.4 长音元音

**需要拖长的位置优先开口度大的元音**（a / ang / ao），**避开 ü、e、i 收尾**。

### 3.5 一字一音节

中文按字落拍，**字数整齐 = 节奏稳**。
英文可靠连读吞音弹性处理，**中文不行，必须守牢字数**。

## 四、交付前核对动作

1. **把交付文档里的发音标注表从上到下读一遍**
2. 对每一条，在 Suno 歌词里**搜标准拼写**
3. 找到 → 替换成音标重拼；已经是重拼 → 确认与表一致

**验证格式**：

- ❌ `表里写 "Potrero" 要读 poh-TREH-roh，但歌词里还是 "Potrero"` → **FAIL**
- ✅ `歌词里 "poh-TREH-roh" 与表一致` → **PASS**

★ **发音表不是文档，是一张必须执行完的替换清单。**
