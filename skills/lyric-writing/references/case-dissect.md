# 拆解表与改稿方向

> 用途：**模式 C（诊断已有歌词）与模式 D（改稿）的固定作业台。**
> 来源：十二行表与填表纪律吸收自 MIT 项目 `jtydhr88/lyric-writing-skills` 的 `lw-case-studies`。本文件为改写重述。

---

## 1. 十二行拆解表

**每拆一首词，填满这张表。栏目固定，不许换。**
（它的价值在于**固定**——换栏目就等于每次都在重新发明判据。）

| # | 看什么 | 具体问法 |
|---|---|---|
| **1** | **立意** | 用**一句人话**说出这首歌只说的那一件事 |
| **2** | **对谁说** | 词里的"你"是谁；有没有"你" |
| **3** | **时刻** | 说话人站在哪个时间点上 |
| **4** | **贯穿物件** | 有没有一个东西反复出现；**它每次是什么意思** |
| **5** | **破题句** | 第一句干了什么：给场景／给动作／给问句／给结论 |
| **6** | **段落分工** | 主歌管什么、副歌管什么；**第二遍变了什么** |
| **7** | **视角** | 第几人称；中途换没换 |
| **8** | **意象系统** | 这些东西**为什么会在同一个画面里**（一句话） |
| **9** | **语言层** | 押哪个辙、换没换；句式长短；离口语多远 |
| **10** | **不对称与留白** | 哪一行故意短；**该说的地方哪处没说** |
| **11** | **与曲的咬合** | 全曲最高音落在哪个字；哪一句旋律被重复用了 |
| **12** | ★ **可迁移的一条** | **这首词教会我一个什么动作**（一句话，**必须带动词**） |

**外加一行，不进表但必须写**：

> ⚠ **学不来的部分**：这首词里有多少好处依赖**这个歌手、这个时代、这段旋律**？
> 那部分记下来，但**不要当成方法**。

## 2. 填表的三条纪律

| # | 纪律 | 为什么 |
|---|---|---|
| **1** | **先整首过一遍再动笔**，过的时候什么都不记 | 边看边记会把结构记成句子 |
| **2** | **只写看得见的** | 「他想表达孤独」不是观察；「全篇只有一个人称，没有'你'」才是 |
| **3** | ★ **填不出来的格子不许空着，要写"这一栏没有"** | **"没有"是发现**——一首好词没有贯穿物件，说明它靠别的东西撑着，**那才是该学的** |

---

## 3. ★ 顺序：从中间填起

**不要从第 1 行开始填。**

```
先填 5–10（破题、段落、视角、意象、语言、留白）  ← 这些是看得见的
再填 11（与曲的咬合）                              ← 需要听
然后回头填 1–4（立意、对谁、时刻、物件）          ← 这些是推出来的
最后填 12                                          ← 一句话
```

★ **理由**：**立意是拆出来的，不是看出来的。**
先写立意，你会把自己的印象写上去，然后在下面九行里找证据来圆它。
先填看得见的东西，立意会自己浮出来——**而且常常和你一开始以为的不一样**。

> **写的时候从上往下，拆的时候从下往上。两个方向不能混。**

## 4. 改稿方向：从"景"移到"人"

**把初稿和定稿并排看，改动几乎全部朝同一个方向——**
**把笔墨从景物挪到人与人的关系上**。

| 初稿常见形态 | 定稿方向 |
|---|---|
| 铺场景、铺天气、铺时间 | **场景还在，但每一处场景都挂在一个动作上** |
| 主语是"风""雨""路" | **主语换成人，风只是背景** |
| 情绪由形容词承担 | **情绪由动作承担**（谁对谁做了什么） |
| 结尾给结论 | **结尾给一个动作或一个静物** |

**可操作的改法**：逐行问两个问题——
1. **这一行里有"人"吗？**（有一个能动作的主语）
2. **这一行的信息，别处有没有承担？**（有就删，别重复铺）

### 4.1 四条改稿方向（与十二行表对应）

| 症状（十二行表里的空栏） | 改法 |
|---|---|
| 第 1 行填不出"一句人话" | **不是改词，是回「道具锚定」重做** |
| 第 2、3 行没有"你"、没有时刻 | 加一个具体的听众称谓 + 一个时间锚（"那天下午""去年冬天"） |
| 第 4 行有物件但含义不递进 | 让它**经历三个不同段落情境**，不是换三个形容词 |
| 第 10 行"该说的没说"是空的 | 说明**全说完了** → 删掉最后一句结论，**留一条线不收** |

## 5. 输出格式（模式 C / D 共用）

拆解完成后，按三块交付：

1. **十二行表**（含"这一栏没有"的诚实填写）
2. **问题清单**（按 P0 / P1 / P2 分级，每条给**具体改法**，不整篇重写）
3. **不要动的亮点**（★ 必须写——只说问题不说亮点，改完会把好东西一起改掉）

**改稿场景**再加一块：**逐行改动清单**（原句 → 新句 + 一句理由）。
